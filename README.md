# AED Placement Lab

Interactive UT Dallas pilot dashboard for exploring AED access, demand scenarios,
retrieval times, and placement alternatives.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production build

```bash
pnpm build
pnpm start
```

The dashboard uses simulated occupancy demand and should be treated as a planning
demonstration, not as a clinical recommendation.
